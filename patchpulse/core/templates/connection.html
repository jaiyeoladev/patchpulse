Set up an app registration

  1. In the Entra admin centre go to Identity → Applications → App registrations → New registration. Name it “{{ spec.name }} (read-only)”, single tenant, no redirect URI.
  2. Open API permissions → Add a permission → Microsoft Graph → Application permissions and add the permissions listed above. Click Grant admin consent.
  3. Under Certificates & secrets create a client secret with a short expiry (for example 6 months) and store it in a secret manager.
  4. Set AZURE_TENANT_ID, AZURE_CLIENT_ID and AZURE_CLIENT_SECRET in your environment (or .env), set DEMO_MODE=false and restart.
  5. Run a scan from the Scans page. Any permission that is missing shows up as a warning on the scan.
